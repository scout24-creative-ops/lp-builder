2. Typography

2.0 Default LP Text

DEFAULT FOR USER-FACING LP COPY (16PX)

Normal LP copy uses the standard body treatment.

font-body-large-regular

SECONDARY / COMPACT (14PX)

Medium body is for metadata, annotations, technical hints, compact secondary copy, or status text. Small body remains for smaller specialist roles.

font-body-medium-regular

Do not reduce typography merely to make content fit. Body Large is the normal LP default; a module policy may explicitly define another available variant when semantically justified.

3.6 Explicit LP Builder Page Spacers

Composition-only Bridge primitives. General sequence: page root → first module → spacer-3xl between independent modules. No default opening spacer; an initial Hero starts directly and is followed by spacer-3xl. Use spacer-xxl instead only between directly consecutive image-right/image-left Split-Teasers in either order, and spacer-4xl for an explicitly requested large section transition. Without an LP Builder footer, exactly one closing spacer-4xl follows the final content module. With an LP Builder footer, exactly one spacer-4xl precedes the footer and no spacer follows it. Use spacers only inside one lpb-explicit-spacing root.

lpb-spacer--xs — Palm 2px · Lap/Desktop 4px
lpb-spacer--s — Palm 4px · Lap/Desktop 8px
lpb-spacer--m — Palm 8px · Lap/Desktop 16px
lpb-spacer--l — Palm 16px · Lap/Desktop 24px
lpb-spacer--xl — Palm 24px · Lap/Desktop 32px
lpb-spacer--xxl — Palm 32px · Lap/Desktop 40px · consecutive image-right/image-left Split-Teaser gap
lpb-spacer--3xl — Palm 48px · Lap/Desktop 64px · default independent-module gap
lpb-spacer--4xl — Palm 50px · Lap/Desktop 80px · page end, LP Builder footer or explicit large transition

8.4 16px Reference

REFERENCE / PRODUCT UI / NOT NORMAL LP DEFAULT

43 genuine 16px glyph classes are verified in the technical inventory. They are reserved for explicit small-control or product-UI contexts; no lpb-icon--16 Builder adapter exists.

Chevron right   Info circle   Arrow right

8.5 Guardrails

  • _24 glyph + lpb-icon--24; _48 glyph + lpb-icon--48. Never mix these pairs.
  • 24px and 48px glyphs are separately optimised; never scale one glyph variant into the other role.
  • Use only an actual class from cosma-icons-static.md; do not invent names or filled variants.
  • No arbitrary font-size, inline sizing, inline colour or separate icon library in normal Builder code.
  • Icons inherit currentColor; use approved text/colour primitives. Decorative icons use aria-hidden="true".
  • If an icon is not inventoried, report ICON GAP / FALLBACK REVIEW; do not substitute a similar glyph automatically. Gondola Lift is currently such a gap.

9. Media / Images

9.1 Approved Asset Roles

TECHNICAL REFERENCE

Teaser / Card

4:3 format. Recommended source: at least 800 × 600 px.

TECHNICAL REFERENCE

Hero / Stage

16:9 format. Recommended source: 960 × 540 px or larger; 1920 × 1080 is a good high-quality option.

9.2 Responsive Content Images

TECHNICAL REFERENCE — capability is defined in component-library.html

Use lpb-image--responsive on raw content images. It provides responsive containment only: large images shrink to their available container; small images keep their intrinsic size and are not upscaled.

Optional media treatment: lpb-image--responsive lpb-radius--media.

9.3 Alternative Text

Informative images require supplied meaningful alt text. Decorative images use alt="".

Do not invent alt text. Missing safe image context is OPEN / ASK.

9.4 Guardrails

  • No automatic crop, object-fit API, aspect-ratio utility, srcset/sizes, picture/source, background-image or mobile art-direction API in v0.1.
  • The CMS ImageWrapper owns advanced mobile-image, caption, link and alignment functionality. Do not recreate it in Bridge CSS or static htmlSource.
  • 1:1, 4:5 and 9:16 are REFERENCE / FUTURE MODULE NEED, not v0.1 Builder API.
